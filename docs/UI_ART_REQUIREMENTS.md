# UI 美术需求表 v1

## 总体风格

| 项目 | 需求 |
|---|---|
| 游戏气质 | 明亮、街机、轻幻想、爽快 |
| 视觉目标 | 信息清楚、按钮有点击欲、卡片有收藏感 |
| 色彩方向 | 高饱和但不刺眼，避免大面积纯平色 |
| 质感 | 需要有边框、纹理、高光、暗部、轻微厚度 |
| 图标 | 使用清晰的透明底图标，优先保证小尺寸可读 |
| 适配 | PC 和手机都要能看清文字与图标 |

## 升级卡片

升级卡是局内最重要的选择界面，需要有明显的“奖励感”和“类型识别”。卡片不再依赖纯色底，而是由美术制作不同功能分类的预制卡片。

### 卡片基础需求

| 项目 | 需求 |
|---|---|
| 卡片数量 | 一次展示 3 张 |
| 构图 | 竖向卡片，标题、核心数值、说明、等级分区清楚 |
| 质感 | 有外框、内框、高光、底纹、阴影 |
| 图标 | 每张卡需要有一个主要图标 |
| 角标 | 每种属性需要右上角标，用于快速识别 |
| 可读性 | 文字区域需要深色或半透明底板，不能直接压在复杂底纹上 |

### 功能分类

| 分类 | 包含内容 | 主色建议 | 视觉关键词 |
|---|---|---|---|
| 玩家属性 | 攻击、攻速、生命、弹速、射程、磁力、经验 | 蓝紫系 `#2F6BFF` / `#4657D9` | 稳定成长、角色强化 |
| 武器弹道 | 弹道增加 | 粉紫系 `#D84CFF` | 多重箭、扩散、火力增强 |
| 宠物强化 | 增加宠物、宠物攻速、宠物攻击、风刃范围 | 绿色系 `#35C96F` | 伙伴、召唤、自然能量 |
| 御剑技能 | 御剑启动、飞剑数量、飞剑伤害、飞剑冷却 | 青蓝系 `#00C8FF` | 飞剑、剑阵、仙术 |
| 稀有通用 | 小幅全能 | 金色系 `#FFD84A` | 稀有奖励、全面提升 |

### 角标建议

| 属性 | 角标图案 | 角标颜色 |
|---|---|---|
| 攻击 | 剑 / 爪痕 | 红色 `#FF5A5A` |
| 攻速 | 闪电 / 速度线 | 绿色 `#55FF88` |
| 最大生命 | 心 / 十字 / 盾 | 青色 `#5FE8FF` |
| 弹速 | 飞弹 / 加速箭头 | 橙色 `#FF9A3D` |
| 射程 | 靶心 / 望远镜 | 黄色 `#FFD84A` |
| 磁力 | 磁铁 | 紫色 `#B45CFF` |
| 经验 | 星星 / 上升箭头 | 亮绿 `#62FF9A` |
| 弹道 | 多箭头 / 三连发 | 粉紫 `#FF5CCB` |
| 宠物 | 爪印 / 小宠物头像 | 绿色 `#35C96F` |
| 御剑 | 飞剑 / 剑阵 | 青蓝 `#00C8FF` |
| 全能 | 皇冠 / 光环 | 金色 `#FFD84A` |

## 宠物背包 UI

宠物背包需要表达“收集、管理、出战”的感觉。整体可以偏轻幻想背包、图鉴、收藏册方向。

### 背包入口

| 项目 | 需求 |
|---|---|
| 图标 | 使用背包图标，不使用纯文字按钮 |
| 风格 | 轻量、醒目、适合常驻大厅界面 |
| 状态 | 默认状态、点击状态、不可用/隐藏状态需要有区别 |

### 背包面板

| 区域 | 需求 |
|---|---|
| 顶部 | 标题、关闭按钮、整体装饰 |
| 上半区 | 已出战宠物区域，需要更亮、更突出 |
| 下半区 | 待机宠物区域，以网格或卡片列表展示 |
| 空槽位 | 虚线框、加号、锁形或暗色占位 |
| 关闭按钮 | 右上角 X 图标，清晰、易点 |

### 宠物卡片

| 内容 | 需求 |
|---|---|
| 宠物头像 | 需要明显，占据卡片视觉中心 |
| 名称 | 清楚显示 |
| 数量 | 重复宠物显示数量角标 |
| 稀有度 | 用边框或底纹区分 |
| 攻击力 | 作为主要数值之一展示 |
| 描述 | 字数较短，注意可读性 |
| 出战状态 | 已出战宠物需要有高亮、标签或发光边框 |

### 稀有度建议

| 稀有度 | 颜色 |
|---|---|
| Common | 绿色 `#55D66F` |
| Rare | 蓝色 `#4B8DFF` |
| Epic | 金色 `#FFD84A` |

## 商店 UI

商店是局外成长入口，需要有“购买天赋卡”的感觉。商店列表暂时只包含攻击、攻速、血量强化。

### 商店整体

| 项目 | 需求 |
|---|---|
| 交互 | 横向滑动卡片列表 |
| 风格 | 与局内升级卡片类似，但更偏商店/养成 |
| 信息 | 天赋名称、等级、价格、效果需要清楚 |
| 状态 | 金币不足时需要灰化或降低亮度 |

### 天赋卡片

| 天赋 | 卡片颜色 | 图案建议 |
|---|---|---|
| 攻击强化 | 红色系 `#FF5A5A` | 剑 / 爪痕 |
| 攻速强化 | 绿色系 `#55FF88` | 闪电 / 速度线 |
| 血量强化 | 青色系 `#5FE8FF` | 心 / 盾 |

### 卡片信息层级

| 层级 | 内容 |
|---|---|
| 一级 | 天赋名称 |
| 二级 | 当前等级 |
| 三级 | 金币价格 |
| 四级 | 简短效果说明 |

## 暂不制作

| 项目 | 说明 |
|---|---|
| 战斗 HUD | 血条、经验条、关卡文字暂不处理 |
| 复杂动效 | 粒子、动态光效、进度小格子暂不处理 |
| 新系统 UI | 排行榜、抽宠动画、移动端控制暂不处理 |
